Merge Dogs

Combine two records for the same real dog. One profile stays; the duplicate is retired. Photos, registration details, health records, source evidence, offspring links and history are transferred. This action is audited and cannot simply be undone.

Find dogs in admin · Merge history

1. Find the two dog records

Search by dog name and select the exact record. If you arrived from the dog list, both records are already selected. The survivor can be changed before confirming.

Select the profile whose URL and identity will remain.

All attached photos and records transfer to the kept profile.
